# Changelog

## 0.1.0 — release candidate

- Added a local read-only Google Sheets MCP with five stable tools.
- Added learner-owned Desktop OAuth with PKCE, loopback callback, bounded retries, and safe errors.
- Added macOS Keychain and Windows Credential Manager token storage.
- Added a deterministic cross-platform MCPB with four native keyring variants and SHA-256 verification.
- Added non-technical setup, privacy, troubleshooting, CI, and release documentation.

Status: unreleased until the Claude Desktop OAuth/Sheets host canary passes.
